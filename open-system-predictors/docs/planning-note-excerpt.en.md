- **Question:** When a learned world model represents its belief as a density matrix and information goes stale over time, can a CPTP (Lindblad/Kraus) predictor that is allowed to dissipate stay calibrated over long horizons, and does a unitary predictor with the same parameter budget lose calibration because of the recurrence of finite-dimensional dynamics?
- **Field's live open question:** The closest precedent, UWM-JEPA (Radha & Goktas, arXiv 2605.25313), states in the paper that "long-horizon retention remains an open question rather than a settled claim", and acknowledges that information flows into system–environment correlations, so that reduced-state probes cannot read it. Its experiments go only up to 5-step rollouts, with joint dimension 16 (system 8 × environment 2). [Translator's note: the paper trains at k = 5 but probes blind rollouts up to k = 20; the technical report's §1 gives the current account.]
- **Attack:** A same-budget comparison against the public code of UWM-JEPA (Apache-2.0), in three steps.
  1. Construct synthetic partially observable Markov tasks for which the Bayes-optimal k-step predictive distribution can be computed exactly, with k from 1 to 200.
  2. Use an environment-dimension sweep and a "pure contraction" control to separate two mechanisms: the **recurrence effect** and **ordinary contraction**. This point came from blind reader 3's comments. [Translator's note: one of three independent readers who, according to the original, were given only the design text; that part of the original is outside this excerpt.]
  3. Add one real data stream: the ETH/UCY pedestrian trajectories already in the repository, reported as exploratory only.
  The models are small (d=8, Liouvillian 64×64); everything can be run on a 16 GB laptop without CUDA.

  [Translator's note: the UWM-JEPA public repository turned out to contain no training code; under deviation D1 in DEVIATIONS.md (2026-10-19, before any run), the unitary baseline was implemented from the paper's specification. See also the note under KT1.]

    [Translator's note: KT1 was redefined before any run by deviation D1 in DEVIATIONS.md.   - **KT2 does the mechanism exist:** On the synthetic task (τ=20), if the KL difference between the trained unitary model (d_E=2) and CPTP over the extrapolation window k∈[51,200] is smaller than 0.01 nats (10 seeds, 95% CI crossing 0), this shows that the mechanism is irrelevant at practical horizons. In that case "unitary vs CPTP" is dropped as the main conclusion, and a null-result technical report is written instead.
  - **KT3 mechanism attribution:** If the unitary model's error does not decrease as d_E increases (no dose–response relation), or the pure contraction control is as good as CPTP, then the main conclusion can only be written as "contraction", not as "recurrence".
