# Third-party data

Experiment E1 and arm B of experiment E2 use third-party data. T1, the A arms of E2 and E3 are fully synthetic. This folder is laid out so that the published code finds the files where it expects them (`src/osw/tasks_ethucy.py` and `src/osw/tasks_series.py` read `data/` at the root of this tree; `src/osw/tasks_aiwq.py` reads `experiments/open-system-world-model/data/`).

## ERA5T category file

The weekly observation and climatology files were obtained through the AI Weather Quest participant portal, which requires registration: `tas_obs_WEEKLYMEAN_*.nc`, `tas_20yrCLIM_WEEKLYMEAN_quintiles_*.nc` and `land_sea_mask_1pt5DEG.nc`, retrieved with the `retrieve_weekly_obs`, `retrieve_20yr_quantile_clim` and `retrieve_land_sea_mask` functions of the Quest's Python package, which need the participant password. `scripts/prep_aiwq.py` (in `experiments/open-system-world-model/`; it needs xarray) reads them from `scripts/ai_weather_quest/data/` at the root of this tree (its docstring refers to a private virtual environment; any Python with xarray works) and converts them into `experiments/open-system-world-model/data/aiwq_tas_quintiles.npz`, the only file the code reads.

**Licence basis.** The public licence file of the Quest's data portal applies CC BY 4.0, but that portal holds the participants' submitted forecasts; the documentation of the password-protected evaluation files states no licence, and the Quest's terms make ECMWF's dataset licences applicable to participants. Our basis for applying CC BY 4.0 to the evaluation files is ECMWF's general licence page together with a written reply from the organisers (2026-09-25, not published) that applies CC BY 4.0 in general wording. On that basis the derived category file is distributed here (owner's decision, 2026-10-31); the weekly observation and climatology files themselves are not. The file holds `cat` (int8, 134 × 121 × 240: each week's quintile category, 0–4), `lat` and `lon` (the 1.5° grid), `dates` (the 134 week dates, 2024-01-15 to 2026-08-03) and `land` (the Quest's 1.5° land–sea mask, land fraction 0–1, converted to float32). With it the E2 arm B runs can be repeated; regenerating the file itself needs the participant password.
